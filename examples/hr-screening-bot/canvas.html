HR screening bot — AI CV reading

AI Product & System Canvas · 2026-10-19 · built with the wizard

GO → offline MVP experiment

AI costs ~$0.0003–0.0009 per CV vs ~$1.00 of HR time, so economics are not the issue. Candidate screening is a high-risk use under the EU AI Act: run the offline bake-off now, and put the compliance baseline in place before Shadow on real candidates.

  • 100–250 responses per vacancy/month
  • manual CV read ≈ $1.00 → AI ≈ $0.0003–0.0009
  • AI tier +$100/client/month
  • risk: false ✗ → unfair rejection
Pattern: Structured output — per-criterion extraction with verbatim quotes; bucket computed by code

1Business problem

What problem costs money/time today?

2 clients × 5 vacancies × 100–250 responses/month; HR spends ~5 min per response (3 on the CV) — 40–100 h/month per client; volume set to grow 5–10×. Lever: revenue growth.

fact

2Business metrics

Which business outcomes improve? When do we stop?

Primary: ≥40% of next 10–20 clients pay for the AI tier. Leading: HR time ≤2 min/response (from 5). Stop: after 6 weeks <40% time saved or HR opens ≥80% of CVs.

fact

8Solution metrics

Quality and performance thresholds

Quality: per-criterion accuracy ≥90%, false-contradicted ≤3%, 100% valid quotes, reject agreement ≥95%, EN/DE/ES gap ≤5 pp. Performance: within one 4 h batch, ≥99% valid outputs.

fact

3Value for customers

For [who] with [problem], we provide [value]

In-house HRs (SMB, IT hiring) without an expensive ATS: a CV check against must-haves with quotes instead of reading every CV — ~3 min saved per response. Manager pays.

fact

5Go-to-market

Who gets it first, first value, expansion gates

1 client, highest-volume vacancy, free 6-week pilot → both clients → new clients after gates. Gates: ≤2 min/response, pilot converts to paid, quality holds.

fact

9Validation strategy

Offline → Shadow → Assist → Auto, rollback

Golden set ~120 CVs (past + synthetic DE/ES). Shadow 2 weeks / 150 responses → Assist. No Auto: AI never decides. Back to Shadow if false ✗ >3% in a weekly sample.

fact

4Cost structure

Costs, unit economics, breakpoint, ROI range

One-time: build 30–40 h × $30, compliance baseline. Ongoing: inference <$35/month at 25K CVs, audits. Unit ≤$0.01/CV. AI tier +$100; payback ~2–6 months.

assumption

6Product shape

Where it lives in the workflow and what it outputs

"AI CV check" block in the existing candidate card: ✓/✗/? per must-have with a CV quote, 2-line summary, "AI suggestion" label. Added by a batch every 4 h.

fact

7AI engine

Architecture pattern and model approach

Extract text → strip protected attributes → one LLM call per CV → code verifies quotes and computes the bucket. HR-written criteria only. Risks: false ✗, misread facts, prompt injection.

fact

10User experience

Actions, AI disclosure, override, privacy
